AASP — API de Intimações

Integração automática ainda não configurada

A AASP permite enviar publicações ao sistema do escritório. É necessário cadastrar este sistema, concluir a habilitação técnica e obter a autorização do associado. A autorização no portal, sozinha, não inicia a importação neste painel.

Abrir autorização do associado na AASPCadastrar o sistema na AASPConsultar cadastro do sistemaOrientações oficiais da AASP

A API entrega intimações e publicações. Ela não libera todos os autos ou todos os sistemas dos tribunais. Senhas e certificados devem ser usados somente nos canais oficiais.

O que você precisa fazer uma única vez

  1. AASP: concluir o cadastro do sistema e a autorização do associado nos links abaixo; depois informar que a liberação foi concluída para conectarmos a API real.
  2. Banco de dados: com o administrador do Supabase, configurar a credencial de servidor em SUPABASE_SERVICE_ROLE_KEY nas variáveis de produção da Vercel. Essa chave deve ficar somente no servidor, nunca no navegador ou no chat.
  3. Outlook: registrar ou liberar o aplicativo Microsoft para o escritório, configurar o identificador e segredo nas variáveis de produção e concluir “Conectar meu Outlook” com a conta remetente autorizada.
  4. Cadastros: confirmar OAB/UF, responsáveis por cliente e e-mails de destino. Vínculos ambíguos continuarão na fila de conferência.

A proteção do agendador e do recebimento foi preparada. O próximo passo técnico é ligar o adaptador da fonte liberada ao canal de recebimento; ele não é uma conexão pronta com a API da AASP.

Fluxo preparado para automatizar a rotina

  1. Habilitar a API da AASP para este sistema e validar a cobertura das OABs e tribunais do escritório.
  2. Complementar, quando necessário, com DJEN para publicações e DataJud para metadados processuais. Essas fontes não substituem os canais de comunicações pessoais ou dados restritos.
  3. Executar a coleta em segundo plano, com fila, reprocessamento de períodos pendentes, controle de duplicidades e conferência da paginação.
  4. Registrar início, fim, fonte, período consultado, quantidades e erros. Alertar a equipe quando uma coleta falhar ou ficar atrasada.
  5. Concluir a configuração do e-mail e encaminhar os novos registros aos responsáveis já confirmados.

O trabalho humano fica concentrado na habilitação inicial, em vínculos ambíguos, falhas persistentes e decisões jurídicas. A cobertura depende do que cada fonte disponibiliza.

Comunicações pessoais do Domicílio Judicial Eletrônico exigem uma integração própria. Algumas operações de acesso ao conteúdo registram ciência e podem iniciar prazo: não serão habilitadas automaticamente por este diagnóstico.
